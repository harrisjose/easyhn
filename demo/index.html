Ask HN: How do you keep your reading list?

92 pointscurious_dev2 hours ago

I've tried a dozen tools and keep coming back to a plain text file. The key insight for me was that friction kills the habit — anything more than two keystrokes and I stop saving things.

Curious what everyone else does. Bonus points for something that syncs.

3 comments
winter_blue · 1 hour ago

I pipe everything through a tiny script. The trick is to normalise the URL first: 

  curl -sL "$1" \
    | pup 'title text{}' \
    | head -1

Then I append to a file. Long links like https://example.com/articles/2026/the-very-long-slug-that-should-wrap-gracefully-instead-of-overflowing wrap nicely. You can also use inline code() mid-sentence.

This is a quoted line, the way some folks format replies.
  • syncs via a private git repo
  • plain text, greppable
  • zero lock-in

This is great, thank you. The git repo idea is what I was missing. How do you handle merge conflicts when two machines save at once?

winter_blue · 40 minutes ago

Append-only, one line per link — conflicts basically never happen, and when they do it's a trivial two-line resolve.
